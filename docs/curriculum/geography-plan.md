## Phase A — რა გაკეთდა

**საერთო კიტი — `src/components/geography/globe/`**
- `GlobeScene.ts` — რენდერერი, OrbitControls, დედამიწა (NASA Blue Marble, `public/geo/earth-blue-marble.jpg`,
  საჯარო საკუთრება), ატმოსფეროს ნათება, ვარსკვლავები, მზის შუქი; `earth` ჯგუფი განედ/გრძედის სივრცეში;
  `onFrame(project)` HTML წარწერებისთვის, `onHover`/`onPick` (raycast → განედი/გრძედი), `focus(lat, lon)`, `viewCenter()`.
- `coords.ts` — lat/lon ↔ Vector3 (SphereGeometry-ის UV-სთან თანხვედრით), ფორმატი „41°43′ ჩ. გ." / „44°47′ აღმ. გრ.".
- `earth.ts` — დედამიწის მეში, ატმოსფერო, ვარსკვლავები.
- `graticule.ts` — ბადე 15°-ით, ეკვატორი, ტროპიკები, პოლარული წრეები, გრინვიჩი, 180-ე მერიდიანი; კურსორის ჯვარედინი.

**გაკვეთილის გარსი**

- `src/components/geography/lesson/GeoLessonPage.tsx` — გვერდი (TopicHeader, ტექსტი, ტერმინები, ქვიზი, წინა/შემდეგი).
- `src/components/geography/lesson/GeoVisual.tsx` — 3D სცენა იტვირთება მხოლოდ საჭირო გვერდზე (`next/dynamic`, ssr: false).

**თემა 9 — `/geography/lesson/solar-power`**: `src/components/geography/solar/` — `SolarScene.ts` (პანელების რიგები,
მზე, სხივები, ნორმალი, ინვერტორი, ქსელი), `solar-math.ts` (დაცემის კუთხე = |90° − (მზის სიმაღლე + დახრა)|, ჰაერის მასა,

„როგორ წარმოიქმნება" ნაბიჯებად თითოეული ტიპისთვის.

  სარტყელი, სადაც ახლა 12:00-ია. სლაიდერები: თარიღი და თბილისის დრო; ღილაკები: 20 მარტი / 21 ივნისი / 23 სექტემბერი /
  21 დეკემბერი; „ბრუნვა“ (2 სთ/წმ). ქალაქები: თბილისი (UTC+4), ლონდონი, ნიუ-იორკი (ზაფხულის დროით), ტოკიო — ადგილობრივი
  დრო, დღე/ღამე. მაჩვენებლები: დღის სიგრძე და შუადღის მზე თბილისში. ორბიტის მინი-სქემა (SVG, ზემოდან ხედი).
